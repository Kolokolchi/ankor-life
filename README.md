# Ankor — redesign

Готовая адаптивная версия главной страницы Ankor на чистом HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Запуск

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Проверка синтаксиса JavaScript: `npm run check`.

## Реализовано

- Адаптивная главная страница, мобильное меню, локальные шрифты и изображения.
- Карточки RENOVA и DETOX, подробности и сравнение продуктов.
- Корзина: добавление, изменение количества, удаление, сохранение в localStorage.
- Переход к оформлению выбранных товаров в существующем магазине ankor.life через Shopify cart permalink.
- История исследований, ответы на вопросы и ссылки на существующие контакты и условия магазина.
- Нативные диалоги с клавиатурной навигацией, видимый фокус и поддержка reduced motion.

Цены, варианты товаров, упаковка и контакты взяты с ankor.life 16 октября 2026 года. В этой статической версии цены являются снимком каталога: окончательные цены и доступность определяет действующий магазин при оформлении. Банковские данные на сайте редизайна не собираются; платёжного сервера здесь нет.

## Файлы

- `dist/index.html` — разметка и содержимое.
- `dist/styles.css` — стили, адаптивность и состояния.
- `dist/app.js` — карточки, сравнение, корзина и меню.
- `dist/assets/` — локальные шрифты, фото и графика.
- `DESIGN.md` — визуальная система.
- `ASSETS.md` — источники изображений и промпты.
- `.openai/hosting.json` — конфигурация отдельной публикации Sites.

Исходный сайт https://ankor.life/ не изменён. Перенос этого дизайна в Shopify требует интеграции разметки в тему магазина.
