# Ankor — redesign

Готовая адаптивная версия главной страницы Ankor на чистом HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

Опубликованный сайт: https://kolokolchi.github.io/ankor-life/

Репозиторий: https://github.com/Kolokolchi/ankor-life

## Запуск

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Проверка синтаксиса JavaScript: `npm run check`.

## Реализовано

- Адаптивная главная страница, мобильное меню, локальные шрифты и изображения.
- Карточки RENOVA, DETOX, RENOVA+ и NIGELLA S., подробности и сравнение четырёх продуктов.
- Корзина: добавление, изменение количества, удаление, сохранение в localStorage.
- Оформление всех заказов через подготовленное сообщение в WhatsApp со всеми позициями, количеством и актуальной суммой.
- Однократное появление блоков при прокрутке и мягкие эффекты наведения; reduced motion и клавиатурная навигация учитываются.
- История исследований, блок лаборатории с настоящими фотографиями, ответы на вопросы и контакты.
- Нативные диалоги с клавиатурной навигацией, видимый фокус и поддержка reduced motion.

Цены предоставлены владельцем 16 октября 2026 года: RENOVA — 41 810 ₸, DETOX — 21 470 ₸, RENOVA+ — 41 810 ₸, NIGELLA S. — 54 200 ₸. Упаковка и информация о новых продуктах проверены по его фотографиям. Старый магазин пока показывает другие цены, поэтому все заказы направляются в WhatsApp с актуальной суммой. Наличие и условия подтверждает менеджер. WhatsApp открывает подготовленный текст, который отправляет сам покупатель.

## Файлы

- `dist/index.html` — разметка и содержимое.
- `dist/styles.css` — стили, адаптивность и состояния.
- `dist/app.js` — карточки, сравнение, корзина и меню.
- `dist/assets/` — локальные шрифты, фото и графика.
- `DESIGN.md` — визуальная система.
- `ASSETS.md` — источники изображений и промпты.
- `.openai/hosting.json` — конфигурация отдельной публикации Sites.

Исходный сайт https://ankor.life/ не изменён. Перенос этого дизайна в Shopify требует интеграции разметки в тему магазина.

## GitHub Pages

Исходники хранятся в ветке `main`. GitHub Pages публикует содержимое `dist/` из ветки `gh-pages`. Для обновления после коммита:

```sh
git push origin main
git subtree push --prefix dist origin gh-pages
```

Главная страница, изображения и шрифты используют относительные пути и работают в подпапке `/ankor-life/`.
